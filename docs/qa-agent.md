# 中央 QA 조율 기능 1차

## 실행 흐름

회원 번역과 분리된 공개 QA 전용 중앙 조율이다.
1. 메시지 입력 → 최초 한 번 전송 동의.
2. 서버가 입력 형식/요청 ID를 검증하고 현재 QA 상태를 계산.
3. AI는 사용자 메시지, 구간 수, 이전 검사 범위, 선택 구간 ID, 경고 구간 ID 목록(최대100개)만 받는다.
4. AI는 run_qa / explain / ask / report / refuse 중 하나를 JSON으로 선택.
5. 서버가 JSON 스키마와 도구 허용 목록을 재검증한 뒤 기존 QA 함수를 호출한다.
6. 설명은 QA 근거를 다시 계산하여 서버가 작성한다. AI의 자유 텍스트나 수정 번역을 화면에 표시하지 않는다.

첨부 파일 본문/파일명/원문·번역문/기존 채팅 전체를 Gemini에 보내지 않는다.
단, 사용자가 입력창에 직접 쓴 문구는 요청으로 전송되므로 문서 내용을 메시지에 붙이지 않도록 동의 안내로 구분한다.
파일 본문은 기존처럼 LTLI 서버가 기본 QA에 사용한다.
외부 모델은 `GEMINI_MODEL`, 키는 `GEMINI_API_KEY`를 서버에서 읽으며 브라우저에는 전달하지 않는다.

## 가능한 범위

자연어 검사 선택, 이전 범위에 대한 후속 요청, 특정/선택된 구간의 경고 설명, 입력 부족 질문,
보고서 안내 및 비허용 요청 거절. 보고서는 기존 다운로드 버튼으로 받는다.
의미 평가, 오역 확정, 번역/수정 생성, 사용자 승인 대신하기, 여러 단계 자율 반복은 제공하지 않는다.
설명은 추측 대신 숫자·태그·자리표시자·URL 등의 실제 검출 값과 규칙 한계를 보여준다.
원문과 번역문은 수정하지 않는다. 모델이 임의 도구를 제안하면 실행하지 않는다.

## 실행/비용 통제

한 사용자 요청당 제공자 호출 최대1회, 자동 재시도 없음. 응답35초/32KiB/출력512토큰 상한.
최대 입력 요청2000자. 모델 문맥에 전체 문서 또는 무한 대화 기록을 넣지 않는다.
SQLite 트랜잭션으로 전체 서비스 기준 시간당20회/UTC일100회 상한을 적용한다.
실패/불명확 응답도 호출 시도에 포함. 요청 ID 해시로 중복 호출 거부.
SQLite에는 해시, UTC일/시간만 저장하며7일 뒤 제거한다. 본문/IP/이메일/언어를 기록하지 않는다.
이것은 무료 공개 시험 운영 제한이며 회원 과금 시스템이 아니다.
환경변수로 한도를 무제한 변경하는 경로를 제공하지 않는다.
Nginx 기존 IP별 속도/연결 제한과 API 동시 처리2개 제한도 유지한다.

## 활성화 — 운영 배포 때 실행, 기본은 비활성

1. 기본 공개 QA 배포 절차를 먼저 완료한다.
2. 새 public_api.py/qa_orchestrator.py와 홈페이지를 함께 배포한다.
3. systemd 단위 파일은 `/etc/ltli-translate/gemini.env`를 선택적으로 읽는다. 키 값은 화면/로그/명령 출력으로 확인하지 않는다.
4. `StateDirectory=ltli-public-qa`가 `/var/lib/ltli-public-qa`를 서비스 사용자 소유로 만든다.
   ProtectSystem=strict 상태에서도 이 디렉터리만 상태 저장에 사용한다.
5. `sudo systemctl edit ltli-public-qa.service`에서 다음 override를 작성한다:

   [Service]
   Environment=LTLI_QA_AGENT_ENABLED=1

6. Nginx public-qa-location.conf의 정규식은 `(check|report|assist)`를 포함해야 한다.
7. `sudo systemctl daemon-reload` 및 service restart, nginx -t/reload.
8. 테스트 메시지로 단일 실제 호출을 검증한 뒤 중앙 조율을 제공한다.
   실제 Gemini 모델 접근/응답은 이번 모의 테스트만으로 보증하지 않는다.

실패 시 기존 QA 결과는 유지하고 명확히 안내하며 기본 파일 QA를 계속 사용할 수 있다.
비활성화는 override의 ENABLED=0 후 restart. 기본 check/report 엔드포인트는 유지한다.
qa.ltli.ai 관리자 인증 정책은 변경하지 않는다.

## 검증

AI 도구 선택, 결과 재계산, 설명 근거, 본문 비전송, 허용하지 않은 도구 거부,
동의/입력 검증, 중복 요청, 동시 한도, 재시작 후 한도 유지, 실패 시 무재시도를 모의 제공자로 검사한다.
실제 서비스 활성화에는 위 환경 설정과 Gemini 호출 확인이 필요하다.
